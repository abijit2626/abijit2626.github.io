Principles / Field rules

Rules I keep arriving at independently.

Four ideas that show up across unrelated projects, each one the reason something in the work above stays quiet.

Rulebook / 04
4
01

Capability is not intent.

Trusted software installs keyboard hooks and reads the clipboard. Flagging capability alone builds a tool analysts learn to ignore.

02

Persistence amplifies risk.

A single observation is a data point. Behaviour that survives over time is a signal.

03

Every signal explains itself.

If I can't say why it scored what it did, nobody can triage it. A model score only amplifies a rule that already fired.

04

Correlation beats volume.

One incident from a complete attack chain is worth more than a thousand isolated alerts.
